# Appirates Crew Match

Planning and rebuild workspace for the Appirates induction event web app.

Start with [docs/00_INDEX.md](./docs/00_INDEX.md).

## Current Locked Direction

- Event-first student experience.
- Google-only login.
- One live induction event.
- Supabase for auth and persistent data.
- Cloudflare Workers plus Durable Objects for realtime.
- Vercel for the Next.js app.
- Polling fallback for weak networks or websocket failure.
